Tour guiado

Accesos directos y ejemplos para empezar rápido con el dashboard y la API.

1) Abrir Grafana

Abrir Grafana
Usuario: admin / Contraseña: admin (por defecto)

Dashboard recomendado: SMA Overview

2) Ver CPU / RAM / Watts

  • CPU: panel CPU % (avg last train)
  • Memoria: panel Mem Peak MB (last train)
  • Watts: CPU Power (RAPL vs Proxy) o Avg Watts (last train)

Si no ves datos, ejecuta un experimento para poblar las series.

3) Ejecutar un experimento

Abrir panel de control

O lanzar directamente por API:

  • Single (control, seed=123)
  • Single (treatment, seed=321)
  • Batch (x5, monitor=10s)

4) Modo Live (tiempo real)

  • Iniciar Live (30s)
  • Parar Live

Observa en Grafana los paneles "Live Avg Watts" y "Live Records/s".

5) Exportar paneles como imágenes

Usa el script scripts/export_grafana_panels.sh para generar PNGs en docs/figures/.

bash scripts/export_grafana_panels.sh

Requiere el plugin grafana-image-renderer y Grafana en http://localhost:3000.
