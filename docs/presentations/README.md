# Presentaciones — Proyecto de Grado

Este directorio contiene decks listos para tu defensa.

## Opciones

- `defensa_10min.md`: versión Markdown simple (compatible con VS Code Preview).  
- `defensa_10min_marp.md`: versión Marp (Markdown → PDF/Slides HTML) con paginación y backups.

## Marp (VS Code)

1) Instala la extensión "Marp for VS Code".  
2) Abre `docs/presentations/defensa_10min_marp.md`.  
3) Usa "Marp: Export Slide Deck..." para exportar a PDF/HTML.

## Notas del orador y backups

- Notas del orador (guion de 10 min y Q&A):  
  `docs/presentations/defensa_10min_notas.md`
- Backups incluidos en la versión Marp:
  - Definiciones de energía, p-values/tamaños de efecto, configuración experimental, stack y hardware.
